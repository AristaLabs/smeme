Run a tree

Keep the matter in the apps you already use: a folder, mail, a CRM record. Your agent gathers from those sources. SMEme asks one question at a time and returns a structured report. The tree must be Deployed and Listed first.

Put the matter where the agent can see it

Point at a folder, attach files, or name the connected apps that hold the facts. The decision tree does not store those files. The agent cites them as evidence for each answer.

Run prompt

Fill in the brackets. Ask the agent to cite a source for every answer and to flag anything that conflicts.
