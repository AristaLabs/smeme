Docs changelog

Release notes for SMEme in-app documentation — what changed in each docs version, including when creator docs became publicly readable.

{# v1.7.0 #}

v1.7.0

July 2026
  • Creator docs are publicly readable (anonymous + signed-in). Delete your account remains authenticated only and is omitted from anonymous navigation.
  • Public pages add unique titles, meta descriptions, absolute canonical URLs, Open Graph tags, and BreadcrumbList / TechArticle (or WebPage) JSON-LD aligned with visible content.
  • Answer-first introductions and product vocabulary pass: decision tree, Deploy/Redeploy, Listed/Hidden, Live/Stale, report. /docs/mcp targets creator setup; public /mcp remains the tool wire reference.
{# v1.6.0 #}

v1.6.0

July 2026
  • Connect your agent — documented MCP authoring: build or revise a draft in chat (agent constructs dt_graph_json; SMEme validates and saves), then review, Deploy, and choose Listed or Hidden in the editor.
  • Docs overview and Building decision trees — visibly advertise building and revising through MCP, with links to the authoring sequence and MCP Tools / MCP Clients community categories.
{# v1.5.0 #}

v1.5.0

June 2026
  • Connect your agent — rewrote the tools section: nine tools (up from six), correct descriptions, and a quota-weight column.
  • Connect your agent — added smeme_reasoning_what_if (scenario comparison) and smeme_reasoning_how_to_reach (repair planning) to the tool reference, tips, and use-case examples.
  • Connect your agent — connector-first MCP setup (URL + OAuth Client ID). Corrected smeme_reasoning_capabilities description (session bootstrap and authoritative tool catalog). Corrected smeme_reasoning_template_check description (drift check, not the worksheet).
  • Plans & usage — quota weights now precise: how_to_reach = 2.5, what_if = 2. Added dormant decision tree behavior on downgrade (grayed out, download-only until under limit). Clarified archive is deployment-dependent.
  • Docs index — removed incorrect "start from scratch" decision tree creation path; creation is wizard-only.
{# v1.4.0 #}

v1.4.0

June 2026
  • Updated Plans & usage — MCP quota: evidence validation now counts as 1 unit (same as evaluate); typical MCP run uses both.
  • Updated Plans & usage — clearer public labels: MCP tool calls (weighting explained in definitions) and AI-assisted wizard builds (replacing wizard-completion jargon).
  • Delete your account — documents that account deletion forfeits remaining Pro prepaid time (unlike Stripe portal cancel) and is not restored on re-signup.
  • Added Delete your account — profile flow, confirmation phrase, data removed vs retained, and how it differs from decision tree delete.
{# v1.3.0 #}

v1.3.0

June 2026
  • Added Plans & usage — tier limits, weighted MCP metering, wizard credits, and quota behavior.
  • Updated Deploy, list, & delete — dashboard usage strip and per decision tree MCP column.
{# v1.2.0 #}

v1.2.0

June 2026
  • Added Download your decision tree — how to export the saved graph as JSON from the dashboard or editor.
{# v1.1.0 #}

v1.1.0

June 2026
  • Redesigned docs layout with persistent sidebar navigation and two-column layout on desktop.
  • Added three-step overview to the docs index (Build → Deploy → Invoke).
  • Added Jump to node and validation issue row documentation in the Building decision trees guide.
  • Added satisfiability check documentation (Z3) to the Deploy, validate & list guide.
  • Updated Connect your agent guide with numbered installation steps and MCP tool reference table.
{# v1.0.0 #}

v1.0.0

Initial release
  • Initial in-app docs: Building decision trees, Deploy & list, and Connect your agent guides.
