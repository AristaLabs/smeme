Ask more

A report tells you the outcome. SMEme can also tell you which answers decided it, what would change it, and what it would take to reach a different outcome. Each answer comes from the tree’s rules, worked out by SMEme.

After a run, keep going in the same chat, and your agent reuses the answers it gathered. You can also ask before you’ve run a case, for example to see what a tree can conclude or what you’d need to show to reach an outcome.

Which answers decided it

After a run that concluded. Shows the smallest set of answers that still leads to the same outcome.

{% set prompt_id = "prompt-decided" %} {% set prompt_label = "Which answers decided it" %} {% set prompt_text = "Which answers decided this outcome? Show me the smallest set that still leads to it." %} {% include "docs/_docs_prompt.html" %}

What if an answer changed

Try a different answer to one question and see whether the outcome or the path changes.

{% set prompt_id = "prompt-whatif" %} {% set prompt_label = "What if an answer changed" %} {% set prompt_text = "What if [the question] were answered [the other option]? Would the outcome change, and would the reasoning still follow the same path?" %} {% include "docs/_docs_prompt.html" %}

What it would take to reach another outcome

The fewest answer changes that would lead somewhere else. Name the answers that can’t change, and SMEme keeps them fixed.

{% set prompt_id = "prompt-reach" %} {% set prompt_label = "What it would take" %} {% set prompt_text = "What's the smallest set of answer changes that would lead to [the other outcome] instead? Keep [answers that can't change] fixed." %} {% include "docs/_docs_prompt.html" %}

When the run didn’t settle on one outcome

Find out which open questions matter and where each answer would lead.

{% set prompt_id = "prompt-unsettled" %} {% set prompt_label = "Settle an open run" %} {% set prompt_text = "This run didn't reach a single outcome. Which open questions would settle it, and where would each answer lead?" %} {% include "docs/_docs_prompt.html" %}
