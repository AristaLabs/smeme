Quick start

Copy these prompts into the chatbot you already use. They walk you through connecting SMEme, finding a judgment worth encoding, and building your first decision tree. For connector settings by product, see Connect your agent.

Connect your chatbot

Chat, Claude, and Copilot cannot add the connector themselves. Paste the prompt, then add SMEme in that app’s settings with the values below. A coding agent such as Cursor or Claude Code may add the connector in its own config.

{% set prompt_id = "prompt-connect" %} {% set prompt_label = "Connect prompt" %} {% set prompt_text = "Help me add SMEme as a remote MCP connector in this app. SMEme is a reasoning layer that runs my decision trees. Walk me through the settings in this product. I will paste the MCP endpoint URL and, if this app asks for one, the OAuth Client ID. After I add it, tell me when to sign in, and use the same email I use on SMEme." %} {% include "docs/_docs_prompt.html" %}

If you can edit this client’s MCP config yourself, add a remote Streamable HTTP connector named SMEme with that endpoint, and the Client ID when the client requires it. Leave the client secret blank.

{% include "docs/_docs_connector_values.html" %}

Find a procedure to encode

Ask your agent to look through the policies, saved prompts, and runbooks you already have. A good candidate is a judgment you repeat, with a few questions that change the outcome, and evidence you can point at.

{% set prompt_id = "prompt-candidates" %} {% set prompt_label = "Candidate procedures prompt" %} {% set prompt_text = "Look through my policies, saved prompts, runbooks, and operating procedures in this conversation and in the files I have attached. Propose candidate decision procedures worth encoding in SMEme. For each candidate, say: the judgment I repeat, the few questions that change the outcome, and the evidence I can point at. Skip checklists that are only data lookup or one-off research." %} {% include "docs/_docs_prompt.html" %}

Build the first tree

Fill in the brackets. Attach the policy as a file, a folder, or pasted text. Ask the agent to show the draft before it saves.

{% set prompt_id = "prompt-build" %} {% set prompt_label = "Build template" %} {% set prompt_text = "Build a [name the decision] decision tree in SMEme from [name the policy, prompt, or file]. Follow SMEme's guidance on how to structure it. Where the source is silent, ask me instead of guessing. I will attach the source as [a file, a folder, or pasted text]. Show me the draft before you save it." %} {% include "docs/_docs_prompt.html" %}

Deploy and List

Open the dashboard, choose Deploy, then set the tree Listed so your agent can call it. Details: Deploy, list, & delete.
