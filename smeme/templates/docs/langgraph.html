A deterministic node in a LangGraph workflow

This page is for people building LangGraph workflows and other AI graphs. Your graph gathers evidence. A person admits each answer at an interrupt. SMEme evaluates a deployed decision tree over MCP and returns the next question or a report. The model proposes. It does not choose the conclusion.

The ACME withholding example

The example is an opt-in fictional cross-border withholding decision tree. Loading it creates, Deploys, and Lists one tree on the signed-in account and uses one decision-tree slot. It does not replace the two-question sample that a new account receives.
