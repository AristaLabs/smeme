Upload decision tree

You can add a decision tree you already saved. On the dashboard, under Decision trees, use the file selector to choose a .smeme.json file, then click Import copy. SMEme creates a new decision tree on your account and opens it in the editor.

An Imported copy banner names the file and stays until you Deploy. The new tree starts Hidden and not Deployed, so an agent cannot run it yet. When you want an agent to run it, Deploy it and set it to Listed.

Questions, branches, and conclusions come across. Past runs and the deployed snapshot do not. Uploading the same file again creates another tree and uses another decision-tree slot. The copy belongs to the account that uploads it. Sending someone the file does not share your tree. If they upload it, they get their own copy.

The file

Import accepts a version 2 export, the same envelope Download your decision tree writes: 

{
  "smeme_export_version": "2",
  "decision_tree": {
    "title": "...",
    "graph": { "nodes": [...], "edges": [...], "metadata": {...} }
  }
}
  • smeme_export_version must be "2", and decision_tree.graph must be present. A raw graph and a version 1 file are refused.
  • The id, version number, and timestamps in the file are ignored. Extra fields at the top of the file are ignored. Question and conclusion ids inside the graph are kept.
  • The title is taken from the file and cut at 200 characters.

Limits

  • The upload must be 600 KiB or smaller.
  • The graph must be 512 KiB or smaller, with at most 2,000 nodes and 4,000 edges. No string in the graph may be longer than 8,192 characters. An option label still caps at 2,048 characters.
  • An authority link must be an http or https URL, or empty. SMEme does not fetch the link.

If the file is refused

The dashboard stays on the list and names the problem. Nothing is added to your account. You may see:

  • This file is larger than 600 KiB.
  • This file is not a SMEme export. Download a decision tree as .smeme.json and import that file.
  • This export version is not supported. Import accepts version 2.
  • This file is not valid JSON, or it is nested too deeply to import.
  • Decision tree title is required.
  • This decision tree is too large to import.
  • An authority link must be an http or https URL.
  • This decision tree does not match the export schema, or a problem in the tree blocks import. The dashboard quotes that problem.
  • Your Pro subscription ended with multiple decision trees. Choose which decision tree to keep live before importing another.
  • The decision-tree limit is reached. Delete a tree or upgrade before importing. See Plans & usage.
