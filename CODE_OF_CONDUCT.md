# Code of Conduct

SMEme Core Discussions, Issues, and PRs are for helping people use and improve
the product. Be respectful and stay on topic.

## Expected

- Assume good intent; write in plain language when answering how-to questions.
- Prefer decision-tree / Deploy / Listed / report vocabulary in product talk.
- Keep secrets out of public posts (no `.env`, tokens, private customer data).
- Credit others when reusing example decision-tree JSON they shared under an
  explicit license.

## Not allowed

- Harassment, hate, or personal attacks.
- Spam, advertising, or off-topic promotion.
- Posting credentials, production secrets, or unredacted third-party PII.
- Debating suspected security vulnerabilities in public (use [SECURITY.md](SECURITY.md)).

## Enforcement

Maintainers may hide or lock posts, convert a Discussion to an Issue, or block
accounts that break this policy. Report concerns to **contact@aristalabs.ai**.

This is a short house rule for a small project. It is not a full Contributor
Covenant adoption.
