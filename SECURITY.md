# Security Policy

## Supported versions

Security fixes are accepted for the latest tagged Core release published as `ghcr.io/AristaLabs/smeme`. Check [GitHub Releases](https://github.com/AristaLabs/smeme/releases) for the current supported version; older tags may not receive backports.

## Scope

This policy covers **SMEme Core** software in [`AristaLabs/smeme`](https://github.com/AristaLabs/smeme) and the public Core container image.

It does **not** cover the hosted commercial product at [smeme.ai](https://smeme.ai) (private `smeme-cloud` overlay). Report hosted-only issues through Arista Labs support or the contact below and mark them as hosted.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Prefer one of:

1. **GitHub private vulnerability reporting** on this repository (Security → Report a vulnerability), if enabled.
2. Email **contact@aristalabs.ai** with a description, affected version/tag or image digest, and steps to reproduce.

We will acknowledge receipt and coordinate a fix and disclosure timeline. Please give us a reasonable window before public disclosure.

## Safe harbor

Security research that follows this policy and avoids privacy violations, service disruption, or data destruction is welcome. Do not attempt to access other users' data or production `smeme.ai` customer environments without authorization.
